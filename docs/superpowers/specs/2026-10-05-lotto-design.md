# 로또 통계 연구소 설계

작성일: 2026-10-05. 사용자가 승인한 기능 구성을 구현 가능한 규칙으로 구체화한 문서다.

## 목적과 범위

누구나 휴대폰과 PC에서 접속해 전체 회차 통계를 확인하고 로또 6/45 번호 5게임을 생성한다. 무료 호스팅을 사용하며 로그인, 서버 데이터베이스, 결제, 포함·제외 번호 설정은 만들지 않는다. 통계는 당첨 확률을 높이는 예측으로 표현하지 않는다.

## 구성과 배포

HTML, CSS, JavaScript와 회차 JSON으로 구성하는 정적 웹사이트를 권장한다. 브라우저가 통계 계산, 번호 생성, 기록 저장, 결과 비교를 수행한다. 별도 프레임워크와 차트 라이브러리 없이 구현한다.

무료 공개 저장소의 GitHub Pages를 배포 후보로 사용하고 GitHub Actions에서 데이터 수집과 배포를 실행한다. 계정 접근과 저장소 연결은 실제 공개 단계에서 확인한다. 도메인은 기본 제공 주소를 사용한다. 실제 공식 데이터 접근 방식은 구현 초기에 검증하며, 수집이 차단되면 자동 갱신이 완료됐다고 주장하지 않는다.

## 화면

어두운 배경에 서비스명, 최신 확보 회차, 데이터 갱신 시각, 생성 대상 회차를 표시한다. 생성 방식 선택과 '5게임 생성' 버튼을 가장 먼저 배치한다. 결과는 오름차순 번호 6개로 구성된 5개의 카드로 표시한다.

1~45 번호별 출현 횟수 막대 차트와 많이 나온 번호·적게 나온 번호 목록을 제공한다. 차트에는 숫자 라벨을 붙이고 모바일에서도 모든 번호를 확인할 수 있게 한다. 하단에는 저장 기록과 당첨 비교를 표시한다. 버튼, 선택 입력, 상태 메시지는 키보드와 화면 읽기 프로그램에서 사용할 수 있게 한다.

## 공식 데이터와 갱신

동행복권의 회차별 공식 결과를 기준으로 1회부터 최신 확보 회차까지 수집한다. 회차, 한국 시간 기준 추첨 날짜, 본 번호 6개, 보너스 번호 1개를 저장한다. 회차는 연속되고 중복되지 않아야 하며, 번호는 1~45의 정수이고 본 번호와 보너스 번호는 서로 중복되지 않아야 한다.

매주 토요일 22:17과 일요일 09:17 한국 시간에 갱신을 시도하고 수동 실행도 제공한다. 예약 실행은 지연될 수 있으므로 화면에는 성공한 데이터의 시각을 표시한다. 통신 실패, 형식 오류, 누락 회차가 있으면 기존 정상 파일을 보존하고 실패를 보고한다. 검증이 끝난 전체 파일만 교체한다.

브라우저는 같은 사이트의 JSON을 읽어 공식 사이트에 직접 요청할 필요가 없다. 배포된 사이트의 데이터는 페이지를 열 때 다시 확인한다.

## 통계와 번호 생성

각 회차의 본 번호와 보너스 번호를 동일하게 1회씩 집계한다. 번호 i의 누적 출현 횟수를 c_i라 할 때 많이 나온 번호 중심은 가중치 c_i + 1, 적게 나온 번호 중심은 max(c) - c_i + 1을 사용한다. 완전 무작위는 모든 번호의 가중치를 1로 둔다. 이 정의는 모든 번호가 선택될 가능성을 남긴다.

Web Crypto의 난수로 가중치를 따라 한 번호씩 선택하고 선택한 번호를 후보에서 제거한다. 각 게임은 중복 없는 번호 6개이고 게임 간 같은 조합은 다시 추출한다. 최대 재시도 횟수를 두고 초과하면 실패 메시지를 표시하며 일부 결과를 저장하지 않는다.

화면에는 '과거 출현 통계는 다음 회차 당첨 확률을 높여주지 않습니다'를 표시한다.

## 대상 회차

생성 시점의 한국 시간과 공식 추첨 일정을 함께 사용해 아직 추첨하지 않은 회차를 지정한다. 단순히 최신 확보 회차 + 1로 지정하지 않는다. 추첨 직후 결과 갱신이 늦어도 이미 추첨한 회차를 대상으로 생성하지 않도록 한다. 추첨 경계 시각은 동행복권 공식 안내를 구현 단계에서 확인한다.

공식 데이터가 예정된 지난 추첨보다 뒤처지면 지연 안내를 표시하고 마지막 검증 데이터로 생성한다. 대상 회차를 결정할 수 없으면 생성을 막고 오류를 표시한다.

## 기록과 결과 비교

localStorage에 버전, 생성 날짜, 대상 회차, 생성 방식, 5게임을 저장한다. 같은 브라우저와 같은 사이트 주소에서만 기록이 유지되며 브라우저 데이터 삭제 시 사라질 수 있음을 짧게 안내한다. 개별 기록 삭제와 전체 삭제를 제공하고 전체 삭제는 확인한다.

저장 전후 형식을 검증한다. 저장 공간 부족이나 저장 차단 시 생성 결과는 보여주되 기록 저장 실패를 안내한다. 손상된 기존 데이터를 자동으로 덮어쓰지 않고 기록 초기화 선택을 제공한다.

대상 회차 결과가 없으면 '추첨 결과 대기'를 표시한다. 결과가 있으면 본 번호 일치 수와 보너스 일치 여부를 계산한다. 6개 일치 1등, 5개와 보너스 일치 2등, 5개 일치 3등, 4개 일치 4등, 3개 일치 5등, 나머지는 미당첨이다. 실제 구매 여부와 당첨금은 판단하지 않는다.

## 검증과 완료 기준

작은 실행 가능한 검사 하나로 데이터 유효성, 통계 합계, 가중치, 게임 내 중복 방지, 5게임 조합 중복 방지, 등수 판정, 한국 시간 추첨 경계 처리를 확인한다. 모바일과 PC의 실제 브라우저 화면에서 생성, 기록 유지, 삭제, 결과 비교와 오류 안내를 확인한다.

전체 회차 데이터와 최신 공식 결과를 대조하고 수집 스크립트를 실제 실행한다. 공개 URL과 예약 실행을 확인하기 전에는 로컬 완성과 공개 운영 완료를 구분해서 보고한다.
