## 계정 소유 확인

- [Google Search Console](https://search.google.com/search-console): URL 접두어 속성에 사이트 주소를 등록하고 HTML 파일 또는 메타 태그 소유 확인을 선택한다. DNS 도메인 속성은 github.io 호스트를 소유하지 않으므로 사용하지 않는다. 발급된 확인 파일/태그를 프로젝트에 추가한 뒤 배포하고 확인한다. 사이트맵을 제출하고 URL 검사로 홈 수집 상태를 확인한다.
- [Bing Webmaster Tools](https://www.bing.com/webmasters): 사이트 등록 후 발급된 소유 확인 파일/태그를 배포하고 사이트맵을 제출한다. 이미 확인한 Google 속성이 있으면 가져오기 기능을 확인한다.
- [네이버 서치어드바이저](https://searchadvisor.naver.com/): 웹마스터 도구에서 주소를 등록하고 소유 확인 태그/파일을 발급받아 배포한다. 서비스가 프로젝트 경로 등록을 허용하지 않으면 호스트 루트 소유 확인이 필요하므로 별도 도메인 또는 호스트 루트 저장소 작업이 필요하다. 소유 확인 후 사이트맵 제출·수집 요청을 진행한다.

확인용 값은 각 계정에서 발급되어야 한다. 임의 태그를 넣거나 등록·색인이 완료된 것으로 보고하지 않는다.

## 호스팅 제약과 적용 범위

robots.txt는 [호스트 루트에서 제공해야 한다](https://developers.google.com/crawling/docs/robots-txt/robots-txt-spec). 현재 루트 robots.txt는 404이며 이 프로젝트에서 변경하지 않았다. 하위 경로에 무효한 robots.txt를 추가하지 않았다. llms.txt는 프로젝트 경로 안내 파일이고 소비 여부나 AI 인용을 보장하지 않는다. IndexNow는 키와 소유 확인 범위를 검토한 후 연동하며 이번 변경에 포함하지 않았다.

FAQ는 화면과 JSON-LD가 동일한 데이터에서 생성된다. 검색 결과의 특별한 FAQ 표시나 순위 상승을 보장하지 않는다. OG는 제목·설명·URL을 제공하며 별도 공유 이미지와 블로그·RSS 대량 발행은 포함하지 않았다.

## 재측정: 2026-10-19

자동 알림은 등록하지 않았다. 계정 등록 이후 최근 28일 노출·클릭·평균 순위와 수집 날짜를 기록하고, 집계가 늦는 최근 2~3일은 제외해 비교한다. 현재 계정 지표와 봇 방문 로그가 없어 모두 미측정이다.

| 지표 | 2026-10-05 | 2026-10-19 |
|---|---|---|
| Google/네이버 노출·클릭 | 미측정 | 등록 후 확인 |
| Bing/Google 색인 상태 | 미측정 | URL 검사·웹마스터 도구 확인 |
| AI 검색 출처 인용 | 미측정 | 아래 질문별 출처 URL 기록 |
| AI 크롤러 방문 | 로그 접근 없음 | 호스팅 제약 확인 |

인용 확인 질문: 로또 통계 연구소는 무엇인가 / 로또 출현 통계에 보너스도 포함되는가 / 많이 나온 번호로 당첨 확률이 높아지는가 / 로또 조합을 PNG로 저장하는 방법 / 로또 번호를 5게임 생성하는 방법.

ChatGPT 검색·Perplexity·네이버 검색에서 실제 답변 출처에 해당 사이트가 있는지 확인한다. 날짜·질문·엔진·답변 URL·인용 유무를 함께 기록한다. 일반 HTTP 검사 성공은 검색 색인이나 AI 인용 성공과 구별한다.

## 콘텐츠 백로그

| 질문 | 근거 | 상태 |
|---|---|---|
| 통계에 보너스 번호가 포함되는가 | 실제 집계 방식 | 홈 FAQ 반영 |
| 조합 기록을 이미지로 저장하는 방법 | 사용자가 요청한 기능 | 홈 FAQ 반영 |
| 로또 통계로 당첨 확률이 높아지는가 | 오해 예방·구현 범위 | 홈 FAQ 반영 |
| 별도 질문 랜딩·블로그 | 검색 수요 미확인 | 실적 검색어 확인 후 검수·발행 |

새 글의 자동 대량 발행은 하지 않는다. 실제 검색어가 확인되면 질문 하나에 필요한 답·출처·기준일을 검수하고 전용 페이지를 만든다.
