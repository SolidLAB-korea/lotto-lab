# 검색·AI 인용 최적화 진단

기준일: 2026-10-05. 대상: https://solidlab-korea.github.io/lotto-lab/

|---|---|---|
| SEO | ⚠️ | HTML 200, 제목·설명·H1 존재. canonical·OG·JSON-LD 없음. 사이트맵 404. 통계 수치는 JS 이후 표시. |
| AEO | ⚠️ | 기능 설명·출처는 보이나 질문별 직답·FAQ 구조화 데이터 없음. |

## curl 기준선

- 메인 HTTP 200. 응답 헤더에 X-Robots-Tag 없음, HTML에 noindex 없음.
- 호스트 루트 robots.txt → 404.
- 프로젝트 경로 sitemap.xml, llms.txt → 404.
- 존재하지 않는 페이지 → HTTP 404 정상.
- 노출·클릭·AI 인용·봇 방문: 계정 지표와 서버 로그 접근이 없어 미측정. 0으로 간주하지 않는다.

## 적용 우선순위 제안

1. 기존 데이터로 통계 요약을 정적 HTML에 생성하여 JS 없이 읽히게 한다. 자동 데이터 갱신 배포에서도 재생성한다.
2. 검색 의도를 드러내는 제목·H1, canonical, OG 메타, 서비스 구조화 데이터, 가시 FAQ와 같은 내용의 JSON-LD를 추가한다.
3. 사이트맵·프로젝트 경로 llms.txt, 출처와 산출 방식·기준일·운영 저장소 링크를 제공한다.
4. Google/Bing/네이버 소유 확인 및 사이트맵 제출 절차와 콘텐츠 질문 백로그를 준비한다. 대량 글 발행은 하지 않는다.
5. 2026-10-19 재측정: 색인 상태, 최근 28일 노출·클릭, 질문 5개의 AI 검색 출처 인용 여부. 최근 2~3일은 집계 지연을 고려한다. 자동 일정은 아직 등록하지 않았다.

## 호스팅 제약

이 저장소는 /lotto-lab/ 프로젝트 경로를 배포한다. robots.txt는 호스트 루트에 있어야 하므로 프로젝트 하위에 파일을 만들어도 호스트 정책을 바꿀 수 없다. 루트 저장소 또는 별도 도메인 작업은 별도 범위다. llms.txt는 안내 파일이며 AI 인용이나 검색 순위를 보장하지 않는다.

## 승인 대기

호출한 플러그인의 Phase 0은 진단 후 우선순위 제안에 대한 승인을 요구한다. 위 변경은 아직 구현하거나 배포하지 않았다.
