      로또 번호는 어떻게 생성하나요?

      많이 나온 번호, 적게 나온 번호, 완전 무작위 중 하나를 선택하고 5게임 생성하기를 누릅니다. 한 게임은 1~45의 서로 다른 번호 6개이며, 한 번에 생성하는 5게임의 조합은 서로 다릅니다.

      로또 출현 통계에 보너스 번호도 포함되나요?

      네. 동행복권 공식 결과의 본 번호 6개와 보너스 번호 1개를 함께 집계합니다. 같은 출현 횟수는 번호가 작은 순서로 정렬합니다.

      많이 나온 번호를 선택하면 당첨 확률이 높아지나요?

      아니요. 과거 출현 통계는 다음 회차 당첨 확률을 높여주지 않습니다. 통계 기반 생성은 조합을 선택하는 방식이며 당첨 예측이 아닙니다.

      내 조합 기록을 이미지로 저장할 수 있나요?

      네. 내 조합 기록에서 이미지 저장을 누르면 해당 기록의 5게임과 비교 결과를 PNG로 내려받습니다. 기록은 같은 브라우저에 저장되며 브라우저 데이터 삭제 시 사라질 수 있습니다.
